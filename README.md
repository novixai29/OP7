# أول طلب — OP7

دعوة افتتاح رقمية عربية لمشروع **مطعم**. تعتمد الفكرة على حركة **Receipt Print Reveal** لتقديم معلومات الافتتاح بصورة حديثة وسريعة على الهاتف.

- Template ID: OP7
- التقنيات: HTML، CSS، JavaScript
- الوضع الداكن: لا
- الصور المطلوبة: نعم — `restaurant-space.jpg`
- الخصائص: عد تنازلي، رابط Google Maps، ملف ICS للتقويم، مشاركة Web Share مع نسخ احتياطي، دعم RTL وReduced Motion.

## التخصيص

عدّل بيانات المشروع من كائن `OPENING` في أعلى `script.js` فقط. يمكن لاحقًا استخدام الحقل الاختياري `guestName` لإظهار اسم المدعو بصورة شخصية داخل الدعوة؛ عند تركه فارغًا لا يظهر شيء. ويمكن إضافة حقل تهنئة للضيوف عند طلب العميل، دون أن يتضمن القالب الحالي نموذجًا أو قاعدة بيانات.

أضف ملفات الصور المذكورة إلى جذر المستودع. يعمل التصميم تلقائيًا بخلفية CSS أنيقة عند غيابها، ولا يعرض صورة مكسورة.
